# AOI LAB — 团队效率工具箱

纯前端的团队效率工具箱：案件查询、表格生成器、FOV 选型工具、重复性分析、相关性判断、打光报告生成器。
技术栈：React 19 + TypeScript + Vite + Tailwind CSS 4。所有功能在浏览器本地完成，无需后端。

## 工具

| 编号 | 名称 | 功能 |
|------|------|------|
| 01 | 案件查询 | 上传 Excel，按人员 + 案号查询物料交期状态 |
| 02 | 表格生成器 | 生成重复性 / 相关性评估 Excel 表格，支持 Cognex VisionPro `.vpp` 导入 |
| 03 | FOV 选型工具 | 相机 + 镜头 FOV 计算、目标尺寸反向推荐、设备资料库、JSON 导入导出 |
| 04 | 重复性分析 | 导入重复性 Excel，重算 6σ、定位异常、单点诊断、Before / After、记录中心 |
| 05 | 相关性判断 | 导入对样 Excel，判断 CCD 能否用 y=ax+b 对齐 QV，批量评估多产品多乘坐 |
| 06 | 打光报告生成器 | 填表 + 选型 + 建打光影像段（**上传图片 · 拖拽调位 · 画红圈**）→ 自动生成打光评估报告 pptx（严格复刻现有版式），封面 / 工站页 / 打光影像页全自动，工站与影像页都可增删 |

> 06 当前覆盖**封面 + 工站页 + 打光影像页（含图片与红圈）**（P1 于 2026-09-28、P2a/P2b 于 2026-09-29 交付）；工站环境小图组件盘（P2c）、需求页（P3a）、结论页（P3b）、JSON 存档（P4）待做。

## 使用方式

### 方式一：离线单文件版（推荐，免安装 / 免网络 / 免 Node）

给**没装 Node.js、没网**的电脑用：

1. 在开发机运行 `npm run build:offline`，生成 `offline/index.html`（单文件，含全部数据）。
2. 把整个项目文件夹拷过去，或只拷 `offline/` 文件夹。
3. 对方双击 `start-offline.bat`（或直接双击 `offline/index.html`），浏览器打开即可用。

> 修改了 FOV 数据（`src/fov/data/*.json`）或 06 的 PPTX 模板（`src/lighting-report/assets/template.pptx`）后，重新跑一次 `npm run build:offline` 即可更新离线版（模板以 data URI 内嵌进单文件；模板 P2a 瘦身到 204 KB 后，离线版约 4.3 MB）。

### 方式二：本地开发（需要 Node.js）

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 生产构建 → dist/
start.bat        # Windows：自动检查 Node、依赖与端口后启动
```

> ⚠️ 三种产物**互不通用**，别混用：
> - `offline/index.html` —— 单文件，**可以双击打开**
> - `dist/` —— 多文件，因构建时设了 `base:'/aoi-lab-combined/'`，页面里引用的是
>   `/aoi-lab-combined/assets/...` 这类绝对路径，**用 `file://` 双击必然白屏**；
>   它是给 GitHub Pages 子路径部署用的，请用 `npm run preview` 或起一个静态服务器访问。
> - `npm run dev` —— 日常开发用

### 质量自检

```bash
npm run verify                 # 一次跑完源码级自检（04/05 集成与解析契约、FOV 数据集、启动器、导航、06 门禁 203 断言）
npm run verify:smoke           # 真浏览器冒烟：起 headless Chromium 验证 04/05 的 Shadow DOM 注入真的生效
                               # 需先 npm run build:offline；找不到浏览器时自动跳过（不报错）
npm run verify:correlation-e2e # 05 真表全流程端到端：导真表 → 出结论 → 读渲染结果，截图落到 ../outputs/
                               # 需先 npm run build:offline；默认用 ~/Desktop/案例/1180M 準確性 之前.xlsx
                               # 换表：AOI_CORRELATION_SAMPLE=<绝对路径>；表或浏览器缺失自动跳过

# 06 打光报告生成器
npm run lighting-report:build-template -- "<源报告.pptx>"   # 重建 PPTX 模板（改了占位符清单才需要）
npm run lighting-report:samples                              # 跑出 5 份样张（1/2/3 工站 + 换设备 + 换镜头，含工站→缺陷两层影像页）到 ../outputs/
npm run verify:lighting-report                               # 门禁：203 项断言（模板完整性 + 填充契约 + 参数化 + 工站克隆 + 打光影像段 + 标题条宽度 + 12 页同构样例 + 图片/红圈/媒体/告警/红字规则 + 需求页与模板族注册表）
npm run verify:lighting-report-e2e                           # 真浏览器端到端：80 项断言（先 npm run build:offline）
```

> 离线版仍是**单文件、数据全内嵌**，但 `index.html` 里有 Google Fonts 外链。
> 完全无网时字体会静默回落到系统字体，功能不受影响。

## 功能说明

### FOV 选型工具

- **组合计算**：按相机 Sensor 尺寸和镜头实际倍率计算 FOV、mm/pixel、μm/pixel。
- **按目标推荐**：输入必须完整覆盖的宽高，从可用相机 / 镜头中反向筛选并排序。
- **兼容性检查**：结合接口和镜头像圈资料区分「兼容 / 待确认 / 不兼容」。
- **设备资料库**：用浏览器 IndexedDB 本地保存新增、修改、隐藏、启停状态，支持 JSON 备份 / 恢复。
- **默认资料**：1,147 台面阵相机与 426 款镜头。


### 重复性分析

- 导入 `.xlsx` 重复性表格，在浏览器本地解析并重算 6σ。
- 按 `<10%`、`10–20%`、`>=20%` 显示认可、条件认可和不认可状态。
- 提供总览、异常定位、单点诊断、Before / After 和记录中心。
- 测试记录与工程经验保存在浏览器本机 IndexedDB，不上传。

### 相关性判断

- 批量比对：导入对样 `.xlsx`（每个 sheet 一个乘坐，sheet 内 1#~10# 是样品）。判定按**样品跨乘坐合并**——一个样品要在它出现过的**每个乘坐**上的点位全部达标才算「对上」，取交集而不是各乘坐分别过半，对上数 ≥ 半数（10 个 → ≥5 个）即算成功。
- 补偿值按**检测项目跨乘坐共用一个 `b`**（现场一套测量程序只能填一个补偿）：即 `y = ax + b`，输出「照这个填」的补偿表与对齐矩阵（行 = 样品，列按乘坐分段）。
- 一页到底：结论条 → 识别卡 → 补偿表 → 对齐矩阵 + 残差诊断 → 明细与导出（默认折叠）。支持逐点明细、散点图、复制汇总表、导出补偿后 xlsx / CSV。数据全部在浏览器本地计算，不上传。

### 表格生成器

- 生成重复性 / 相关性评估 Excel 表格。
- 支持导入 Cognex VisionPro `.vpp` 文件，自动识别尺寸检测项目——纯浏览器解析，**无需安装 VisionPro SDK**。

### 案件查询

- 上传 Excel，按人员 + 案号查询物料交期状态。

### 打光报告生成器

- 四段式表单：**封面标题**（项目名 + 「評估報告」两行）→ **产品与需求**（最大外径/厚度/最小公差/相机像素）→ **工站设定**（含每个工站自己的**打光影像段**）→ **预览并生成**。
- **工站可增删**（起码 1 个）：每站填相机 / 镜头（带设备库自动补全）/ 光源 ×2 / 检测项目；可**粘贴 03 的报告文本一键带入**，也可手工填，还能人工覆盖自动算出的 FOV / DOF / Resolution 等值（每条覆盖都给出告警）。
- **打光影像段（工站卡内部）**：按 **工站 → 缺陷** 两层组织。缺陷组可加/删/改名，也能按上面的检测项目一键建组；组内每页可选**普通 / 特殊**版式（源报告里两种骨架的说明框宽度不同），并填**名称**与**说明**（一行一段，留空则说明整段消失）。改缺陷名或切版式时，**只跟随"还是默认值"的名称，不覆盖手写过的内容**。
- **产物页序实时可见**：右侧顶部列出逐页标签（`封面 → 需求 → [工站1 → 它的影像…] → [工站2 → 它的影像…] → 結論`），页数与按钮上的数字同源，**界面显示的 = 生成的**。
- **自动算的部分**：FOV / Resolution 直接复用 03 的算法（保证与 03 一致）；DOF 用本厂通用 **40% 折减**（口径与 03 的"× 倍率"不同，是刻意为之）。
- **严格复刻**源报告的版式、字号、`標楷體`、光路图与红色标注；封面 / 全部工站页 / 打光影像页骨架自动填，需求页与结论页原样带过。
- 生成后浏览器直接下载 `.pptx`，可在 WPS / PowerPoint 里继续手改。若某字段没填，**该处会以占位符原样留在 pptx 里**（不会产出一份"看起来完整、其实缺字段"的文件），并给出告警。
- **打光影像页可以贴图**：`＋ 加图片`（可多选，**上传即降采样**成 JPEG：长边 > 1600 才压、PNG 先铺白底、同一张图跨页只存一份）。默认**自动摆放**，拖任意一张图即整页切手动并固化其余位置，点「重新自动摆放」回到自动。切到「画红圈」可在图上拖框生成红圈（导出成**真的椭圆 shape**，不是画在图上）。
- 说明里用 `**文字**` 表示**红字加粗**（与源报告一致，星号本身不会印到 PPT）；名称行结尾的 `-特殊` 也会自动标红加粗 —— 那两处是源报告的实际做法。
- 单页最多 12 张图；说明写太多把图片区压到下限、或手动摆放拖出页面，**都会告警**而不是静默出问题。
- 数据全部在浏览器本地处理，不上传。

## 架构

```
src/lib/        # 纯逻辑：VPP 解析、Excel 生成、案件查询解析、繁简转换
src/fov/        # FOV 工作台、设备资料库、IndexedDB 存储
src/repeatability/ # 重复性分析 V1.6 React 宿主 + 隔离源码
src/correlation/ # 相关性判断 React 宿主 + 隔离源码
src/lighting-report/ # 06 打光报告生成器：UI + assets(pptx 模板) + domain/(填充·克隆·页序·排版，浏览器与 Node 共用)
src/components/ # 表格生成器、案件查询、页面布局
```
