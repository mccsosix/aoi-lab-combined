# AOI LAB FOV 交付验收报告

验收日期：2026-08-12

## 已完成范围

- 在原 AOI LAB 首页新增 Tool 03“FOV 相机与镜头选型”，并提供独立 `/fov` 路由。
- 实现组合计算、目标反向推荐、完整宽高覆盖、目标旋转、可调倍率、接口与像圈兼容性判断。
- 实现本机资料库 CRUD、内置资料隐藏/恢复、启停、复制和字段校验。
- 实现 IndexedDB 自动保存、JSON 导出、导入预览及冲突决策。
- 将组合计算结果改为可复制的七行报告参数；报告 DOF 使用资料值乘以实际倍率，Lens Resolution 使用镜头像方 MTF 的物方半周期估算。
- 相机选择后默认隐藏接口不匹配或像圈不足的镜头，并提供“显示不兼容镜头”开关；光学格式用于展示，覆盖判断使用实际毫米对角线。
- 生成无需 Node.js 的 Windows 本地静态包和仅监听 `127.0.0.1` 的启动器。

## 本次镜头资料优化

- 镜头库由 426 款扩展为 623 款（燦銳 38→227、視清 388→396），原 426 款稳定 `id` 全部保留，新增 197 款以新资料自带 `id` 入库，无重复 `id`、无同品牌同型号重复。
- `Lens Resolution` 改为优先级计算：优先采用厂家直接物方解析度 `objectSpaceResolutionUm / 1000`（单位 mm），其次使用像方 MTF 的物方 half-pitch 估算；两者均缺失时明确标注“资料未提供”，不再显示为 `0` 或猜测（原 426 款中可显示镜头解析度的数量由 270 增至 326）。
- 新增保留 `object_space_resolution_um`（56 款）、`depth_of_field_min_mm` / `depth_of_field_max_mm`（58 款）等字段；DOF 范围按 min/max 分别乘以实际倍率显示，不先求平均。
- 报告 `Sensor Size` 区分厂家标称像素与按分辨率计算值（后者注明“按分辨率计算”）、缺失靶面规格显示“靶面规格待补”、缺失帧率显示“fps=待补”，避免把计算像素误认为 Sensor Size。
- 新提取报告（`lens-extraction-report.json`）与最终镜头 JSON 在数量、品牌、状态上完全一致（623 / 227+396 / 411+212）。

## 页面验收

- 桌面预览检查了 AOI LAB 首页、组合计算、目标推荐、设备资料库和导入/导出弹窗。
- 指定组合 `MV-CH250-90UC` + `DTCM110-80H-AL` 显示 FOV `61.54 × 61.54 mm`、Resolution `0.01202 mm/pixel`、DOF `±3.08 mm`、Lens Resolution `0.018 mm/pixel`，并提示像圈需要 `18.10 mm`、镜头支持 `16.60 mm`。

- 响应式规则在 1080、780、680 px 三个断点收敛为双列/单列，并为推荐表保留局部横向滚动。
- 弹窗支持 Escape 关闭、焦点约束和明确的关闭按钮。

## 已知边界

- Web 和本地包会将大体量默认资料打入前端脚本，构建会提示单块超过 500 kB；不影响离线运行，后续若继续扩充资料可再做按品牌分包。
- Windows PowerShell 启动器已做静态结构和安全断言；当前 Linux 验收环境无法实际双击运行 `.bat`，交付后应在目标 Windows 机器做一次烟雾测试。
- FOV 和兼容性结果用于选型初筛，不替代机械干涉、工作距离、畸变、景深和实物装机验证。

## 已知数据缺口（待官方来源补充）

- 当前 1,135 台相机中仍有 34 台缺 `fps`：32 台度申 / Do3think 全部缺失，2 台海康（`MV-CT032G-38GM01-MAX-35L-WBC`、`MV-CT050G-24GM01-MAX-16L-WBC`）。报告已对缺失帧率显示 `fps=待补`，未做猜测填充。补充需来自厂商官方产品页 / 手册，并保留来源 URL、获取日期与是否满分辨率帧率，禁止从型号后缀或同系列近似型号推断。
- 度申相机多数同时缺失 `nominalMegapixels` 与 `sensorFormat`，报告以“按分辨率计算”与“靶面规格待补”透明呈现，待官方资料补齐。
