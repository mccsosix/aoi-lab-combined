# FOV 相机与镜头选型页面布局重构设计规范

> 目标：将现有 **FOV 相机与镜头选型** 页面重构为参考图所示的布局与视觉层级。  
> 本文档重点约束 **页面结构、布局比例、信息层级、交互区域和视觉样式**。  
> **不要修改现有业务计算逻辑、数据库结构、相机/镜头数据、FOV 算法、兼容性判断逻辑。**

---

## 1. 改版目标

当前页面功能已经完整，本次改版主要解决以下问题：

1. 顶部标题区域过高，核心操作区进入视野太晚。
2. 左右两栏比例不够稳定，输入区占用过大。
3. 结果区缺少视觉重点，FOV / 精度 / DOF 等核心结果不够突出。
4. 页面信息层级偏“表单 + 表格”，缺少工程工具的仪表盘感。
5. 相机、镜头选择区域需要更加紧凑。
6. 保留现有 AOI LAB 的工业风格，不改成普通后台管理系统。

最终视觉应接近参考图：

- 深蓝工程网格背景
- 米白 / 暖白工作面板
- 青色作为主强调色
- 橙色作为警告 / 强 CTA / 底部说明色
- 大标题但不占用过多高度
- 左侧输入、右侧结果
- 右侧结果明显比左侧更重要
- 页面整体紧凑、专业、工程化


# 38. 给代码 AI 的最终执行说明

请直接基于当前项目代码进行页面重构。

本次任务的原则：

> **保留功能，重做布局；保留品牌风格，提升信息层级；突出结果，压缩无效空间。**

优先保证：

1. 现有计算逻辑完全不受影响。
2. 数据读取 / localStorage 不受影响。
3. 相机与镜头选择逻辑不受影响。
4. UI 结构接近本文档和参考图。
5. 不需要为了 UI 重构去重写整个项目。
6. 优先复用现有组件和 CSS 变量。
7. 如果现有 CSS 结构混乱，可以新增页面级 Layout / Module CSS，但避免全局污染。
8. 完成后同时检查：
   - 1440 × 900
   - 1600 × 900
   - 1920 × 1080

最终效果重点不是“完全一像素复刻参考图”，而是：

> **达到相同的页面结构、空间关系、视觉层级和工业工具感。**
