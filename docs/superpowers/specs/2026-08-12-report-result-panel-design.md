# FOV 报告结果面板与镜头兼容筛选设计

日期：2026-08-12

## 目标

将组合计算右侧由通用指标卡改成可直接用于报告的参数清单，并在左侧根据所选 CCD 的接口和传感器实际对角线默认过滤镜头。用户仍可切换显示不兼容镜头进行特殊核算。

## 主报告清单

右侧主区域按固定顺序显示：

1. `CCD`：所选相机型号。
2. `Sensor Size`：`标称像素（光学靶面规格）/ fps=帧率`。
3. `Lens`：所选镜头型号。
4. `FOV`：`宽 × 高 mm`。
5. `DOF`：`镜头原始 DOF × 实际倍率`，并在次行显示计算过程。
6. `Resolution`：水平物方分辨率，单位 `mm/pixel`，保留 5 位小数。
7. `Lens Resolution`：依据镜头像方 MTF 与实际倍率换算的物方 half-pitch 估算值；主报告按用户报告习惯显示为 `mm/pixel`，详细参数中明确标记为 MTF 估算。

主区域提供“复制报告参数”按钮，复制上述七行纯文本。兼容性状态紧接报告清单显示，不折叠，因为接口或像圈问题会影响报告是否可用。

## 计算口径

### FOV 与相机 Resolution

- `FOV 宽 = 传感器宽 mm / 实际倍率`
- `FOV 高 = 传感器高 mm / 实际倍率`
- `Resolution = FOV 宽 mm / 水平像素数`

### DOF

按用户确认的项目口径：

- `报告 DOF = 镜头原始 DOF × 实际倍率`

固定倍率镜头使用 `magnification`；可调倍率镜头使用当前计算实际采用的倍率。报告同时显示原始 DOF、倍率和乘法结果。若资料源明确为 `±` 景深则保留 `±`；否则不自行增加正负号。原始 DOF 或倍率缺失时显示 `—`。

### Lens Resolution

镜头资料存在像方 MTF 下限 `MTF lp/mm` 时：

- `Lens Resolution = 1 / (2 × MTF × 实际倍率)`

结果为物方 half-pitch 估算值。MTF 或倍率缺失时显示 `—`，不自行猜测。

## Sensor Size 与镜头覆盖

`2/3″`、`1″`、`1.1″` 等光学格式用于报告阅读，兼容性不依赖字符串大小排序，而使用实际毫米数：

- 相机需求：`sensorDiagonalMm`
- 镜头能力：`maxSensorDiagonalMm`
- `相机对角线 <= 镜头像圈` 才能完整覆盖。

同时规范化并比较相机与镜头接口。兼容性主提示显示：

- 兼容：接口匹配，镜头像圈完整覆盖。
- 不兼容：列出接口差异或 `相机需要 X mm / 镜头支持 Y mm`。
- 待确认：任一关键资料缺失。

## 左侧镜头筛选

选择 CCD 后，镜头下拉框默认只显示：

- 已启用且未隐藏；
- 接口明确匹配；
- 镜头像圈明确覆盖相机传感器；
- 或兼容性资料缺失、需要人工确认的镜头。

明确不兼容的镜头默认隐藏。左侧增加“显示不兼容镜头”开关；开启后恢复显示全部符合品牌与关键词条件的镜头。切换相机导致当前镜头被过滤时，自动选择第一款可显示镜头；若没有镜头则清空选择并显示说明。

“按目标推荐”维持现有规则：默认排除明确不兼容和待确认组合；勾选“包含兼容性待确认组合”后仅放宽待确认组合，明确不兼容组合仍排除。

## 查看更多参数

报告清单下方提供原生可展开的“查看更多参数”，默认收起，内容包括：

- 对角 FOV、水平和垂直 Resolution、实际倍率；
- 相机分辨率、传感器物理宽高/对角线、光学格式、像元尺寸、帧率、接口；
- 镜头类型、工作距离、原厂 DOF、DOF 光圈、MTF、支持像圈、接口；
- 完整兼容性原因、资料复核状态。

## 数据模型与来源

默认资料从交接包原始 JSON 重新保留以下字段：

- 相机：`sensorFormat`、`fps`、`pixelSizeXUm`、`pixelSizeYUm`、`sensorModel`、`nominalMegapixels`。
- 镜头：`sensorFormat`、`imageMtfLpMmMin`、`depthOfFieldAperture`、`aperture`，以及能从来源明确确认的 DOF 正负格式。

标称像素优先使用资料源中的市场标称值；缺失时使用现有 megapixels 数值并标注为近似值。所有新增字段也进入本地资料库编辑、IndexedDB 保存及 JSON 导入导出，旧备份缺少新增字段时保持可导入并显示 `—`。

## 视觉与交互

- 延续 AOI LAB 现有纸张面板、深蓝描边、青色强调色。
- 报告字段采用左侧固定标签、右侧加粗值，窄屏切换为上下排列。
- 复制成功后按钮短暂显示“已复制”；失败时显示可见错误，不静默失败。
- `查看更多参数` 使用键盘可操作的 `<details>/<summary>`。
- 兼容性状态保留现有颜色，并增加需求像圈与支持像圈的明确数字。

## 测试与验收

- 公式测试：实际倍率 DOF、MTF half-pitch、缺失数据。
- 兼容筛选测试：2/3″相机配1″镜头、1.1″相机配1″不足、接口不匹配、资料缺失。
- 组件测试：报告七行、复制文本、折叠参数、显示不兼容开关、相机切换后的镜头选择。
- 数据测试：指定型号 `MV-CH250-90UC` 与 `DTCM110-80H-AL` 的 fps、光学格式、MTF、倍率和 DOF 被正确接入。
- 页面预览检查桌面与窄屏布局，并复跑 lint、单元测试、Web 构建、数据校验和 Windows 源码包测试。

## 非目标

- 不把 FOV 数学结果当作装机保证。
- 不用光学格式字符串替代实际像圈判断。
- 不改变目标推荐的完整宽高覆盖规则。
- 不发布线上版本；最终更新本地工具包和完整源码包。
