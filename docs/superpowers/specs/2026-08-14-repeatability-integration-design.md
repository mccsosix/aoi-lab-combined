# AOI LAB 重复性分析整合设计

## 目标

把用户提供的 `AOI_LAB_Repeatability_V1.6_UI规范对齐(1).html` 整合进现有 React + Vite AOI LAB 首页工具箱，并保留其完整分析功能。首页新增 `04 重复性分析` 可用模块，同时新增 `05 相关性分析` 占位模块，显示“开发中”且不可点击。

## 已确认范围

- 04 重复性分析：可点击，在当前 AOI LAB 页面下方展开。
- 05 相关性分析：仅首页卡片占位，不展开、不挂接现有 `src/lib/correlation.ts`。
- 不改动现有 01 案子物件查询、02 表格生成器、03 FOV 选型工具行为。
- 不重写 V1.6 的业务算法，不删除其总览、异常定位、单点诊断、Before / After、记录中心、IndexedDB、本地备份等能力。
- 保留项目现有未提交修改，不回退 FOV 数据或启动脚本。

## 架构选择

### 方案 A：完全重写为 React 组件

优点：长期维护最纯粹。缺点：V1.6 单文件超过 1700 行，包含大量 Excel 解析、DOM 渲染、IndexedDB、诊断逻辑，直接重写回归风险高，不适合本次“先稳定整合”的目标。

### 方案 B：iframe/独立 HTML 跳转

优点：最快、隔离最彻底。缺点：不符合 AOI LAB 现有“首页下方展开工具”的交互，也不利于返回工作台和统一布局。

### 方案 C：React 宿主 + Shadow DOM 隔离运行原 V1.6（采用）

新增 `RepeatabilityWorkbench` React 组件，Vite 以 `?raw` 导入 V1.6 源 HTML。组件把页面内容挂载到 Shadow DOM 中，复用原 CSS 和 JS，避免其 `body`、`.btn`、`table` 等通用选择器污染 AOI LAB 主站。脚本中的选择器根节点改为 ShadowRoot；“返回工作台”事件改由 React `onBack` 控制。

这个方案保留 V1.6 现有功能，同时满足“内部展开、非 iframe、风格隔离、最小业务回归”的要求。

## 首页设计

### 04 重复性分析

- 编号：04
- 标题：重复性分析
- 描述：导入重复性 Excel，自动重算 6σ，定位异常并辅助调机判断。
- 标签：`6σ`、`异常定位`、`本机记录`
- 图标：二维线稿，表达“重复测量 + 趋势分析”，遵守现有 Icons 风格。
- 点击后设置 `activeTool = 'repeatability'`，在工具卡下方展开 `RepeatabilityWorkbench`。

### 05 相关性分析

- 编号：05
- 标题：相关性分析
- 描述：用于后续 QV / CCD 等相关性评估。
- 标签：`开发中`
- 卡片显示禁用状态、`aria-disabled=true`，不响应鼠标和键盘打开操作。
- 不连接现有 `src/lib/correlation.ts`，避免用户误以为分析前端已经可用。

## RepeatabilityWorkbench 行为

- React 外层负责生命周期、关闭工具、错误兜底。
- Shadow DOM 内负责 V1.6 现有 UI 与脚本。
- 隐藏 V1.6 独立页面自己的 AOI LAB 顶部栏与全局页脚，避免与主站 Header/Footer 重复。
- 保留 V1.6 自己的页面标题、文件区、5 个页签和所有分析内容。
- `btnBack` 点击调用 React `onBack()`，不再执行 `history.back()`。
- 独立页面的导出备份、帮助、数据管理能力继续可从工作区内部访问；若顶部栏隐藏，则将必要操作保留在可见区域或通过现有记录中心入口访问。
- 组件卸载时清理挂在 `window` 上的 ShadowRoot/回调引用，避免再次打开重复绑定。

## 数据与安全边界

- Excel 仍在浏览器本地解析，不上传。
- V1.6 IndexedDB 数据库名 `aoi-lab-repeatability` 保持不变，因此独立 HTML 与整合版可共享同一浏览器域下的数据语义；不同部署域仍各自隔离。
- 不修改用户的重复性判定逻辑：6σ <10% 完全认可，10–20% 条件认可，>=20% 不认可。

## CSS 与响应式

- Shadow DOM 隔离 V1.6 CSS，避免覆盖 `src/index.css`。
- 将原 `:root` 变量在 Shadow 宿主中可用，并给内部页面增加嵌入模式修正：移除外层深蓝 body 背景依赖、页面最大宽度改为宿主可用宽度、隐藏重复顶部栏/页脚。
- 首页工具网格继续使用现有响应式规则。新增禁用卡样式：降低饱和度/透明度，但文字必须清晰，且不能仅靠颜色表达“开发中”。

## 验证标准

1. `ToolId` 包含 `repeatability`，不包含可打开的 `correlation`。
2. 首页存在 04 可点击卡和 05 禁用卡。
3. 点击 04 在当前页面展开，不跳转、不 iframe。
4. 重复性工作区能够加载 V1.6 的 5 个页签和文件输入。
5. `btnBack` 能收起工作区并返回 AOI LAB 首页状态。
6. V1.6 样式不影响首页 ToolCard、FOV、表格生成器和案子查询。
7. TypeScript 编译通过。
8. 自定义集成校验脚本通过。
9. README 功能列表更新为 01–05，其中 05 标记开发中。
