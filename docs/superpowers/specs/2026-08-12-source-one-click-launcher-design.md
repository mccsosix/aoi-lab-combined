# 源码包一键启动器设计

日期：2026-08-12

## 目标

在完整源码包根目录提供 `一键启动.bat`。Windows 用户双击后可以首次自动安装依赖、启动源码开发服务器并打开浏览器；后续运行不重复安装依赖。

## 范围

- 在项目根目录增加 `一键启动.bat`。
- 在 `package.json` 增加 `dev:open` 命令，用 Vite 启动开发服务器并打开默认浏览器。
- 扩展本地包验收脚本，验证源码启动器的关键行为。
- 更新 README 的源码启动说明。
- 重新生成并替换完整源码压缩包。

不修改现有 `AOI-LAB本地工具.zip` 的离线启动方式，也不发布线上版本。

## 启动流程

1. BAT 将工作目录切换到自身所在的项目根目录。
2. 检查 `node` 和 `npm` 是否可执行。任一缺失时，显示 Node.js 22.13+ 安装提示并暂停退出。
3. 若 `node_modules` 不存在，执行 `npm install`。安装失败时显示中文错误并暂停退出。
4. 执行 `npm run dev:open`，由 Vite 启动开发服务器并打开默认浏览器。
5. 开发服务器运行期间保留命令行窗口；关闭窗口或按 `Ctrl+C` 即停止服务。
6. 服务异常退出时显示中文错误并暂停，避免窗口一闪而过。

## 文件职责

- `一键启动.bat`：Windows 环境检查、首次安装和错误提示。
- `package.json`：提供可在命令行独立复用的 `dev:open` 脚本。
- `tests/local-package.test.mjs`：验证源码包根目录 BAT 存在，并断言其环境检查、首次安装和启动命令。
- `README.md`：说明双击启动与首次联网安装依赖的行为。

## 错误处理

- 缺少 Node.js/npm：不尝试安装系统软件，只提供明确提示。
- `npm install` 失败：停止启动，保留错误输出。
- 开发服务器失败：返回非零状态，显示失败提示并暂停。
- 路径含空格或中文：所有路径通过 `%~dp0` 切换，不拼接未加引号的绝对路径。

## 测试与验收

- 先增加失败测试，证明根目录 BAT 尚不存在或缺少约定逻辑。
- 实现后单独运行 Node 本地包测试，再运行完整 `npm test`、`npm run lint` 和资料校验。
- 重新打包后使用 `unzip -t` 检查压缩包完整性，并确认 `一键启动.bat` 位于 ZIP 根目录。
- 当前 Linux 环境不能实际执行 BAT；自动化验证脚本文本与包结构，最终仍建议在 Windows 做一次双击烟雾测试。
